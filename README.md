
# Telegram Bot with GPT Integration
This is a simple Telegram bot using Flask and aiogram with GPT-4 integration.

## How to Deploy on Render

1. Upload the ZIP file containing these files to Render.
2. Set the environment variable `TELEGRAM_API_TOKEN` with your Telegram bot token.
3. Deploy your web service.

Make sure to configure UptimeRobot or another pinging service to keep your bot alive.

## Requirements
- Python 3.8+
- Flask
- aiogram
- g4f
